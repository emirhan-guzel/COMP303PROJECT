Project Description
GastroAnalyst is a university team project developed as part of our coursework. The project simulates a smart kitchen system and focuses on data processing and system logic.

My Contributions
I worked on the following modules:

models.py – Data models and system structure
kitchen.py – Kitchen process simulation using multithreading
analysis.py – Data processing and basic intelligence logic

The project was developed on a single computer and uploaded to GitHub from that machine. Therefore, my branch does not show separate commits, but I actively contributed to the listed modules.
